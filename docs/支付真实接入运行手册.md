# 真实支付接入运行手册

> 适用：btry 内核的真实渠道支付（当前实现支付宝电脑网站支付）。本文覆盖**有公网域名**与**无公网域名（轮询结算）**两种部署形态，以及后续迁移到域名服务器的切换清单。

## 1. 两种运行模式

| 模式 | 适用 | 结算方式 | 要求 |
|---|---|---|---|
| 回调模式（推荐） | 有公网 HTTPS 域名 | 支付宝异步通知为主，主动查单兜底 | `ALIPAY_NOTIFY_URL` 公网可达 |
| 轮询模式 | 按量计费/无域名/未备案服务器 | 内核 `PaymentQueryJob` 定时查单 | 服务器能出网访问支付宝网关即可 |

轮询模式不改代码：`app.payment.query.enabled=true`（默认）时，内核每 30 秒扫描 `PAYING` 支付单并向支付宝查单，确认成功后走与回调完全相同的确认逻辑（幂等、金额校验、发件箱）。

## 2. 配置

### 2.1 基础渠道配置（两种模式都要）

| 环境变量 | 说明 |
|---|---|
| `PAYMENT_PROVIDER=alipay` | 切到真实渠道；`prod` profile 下 mock 会被启动门禁拒绝 |
| `PAYMENT_APP_ID` | 接入方标识，写入支付单 `app_id`；默认 `btry` |
| `ALIPAY_APP_ID` | 开放平台应用 APPID |
| `ALIPAY_PRIVATE_KEY` | 应用私钥，PKCS8 纯 Base64 单行 |
| `ALIPAY_PUBLIC_KEY` | **支付宝公钥**（不是应用公钥），用于回调验签 |
| `ALIPAY_SELLER_ID` | 可选；配置后回调会校验 seller_id，生产建议配置 |
| `ALIPAY_GATEWAY_URL` | 生产 `https://openapi.alipay.com/gateway.do`；沙箱 `https://openapi-sandbox.dl.alipaydev.com/gateway.do` |
| `ALIPAY_SIGN_TYPE=RSA2` | 固定 RSA2（公钥模式） |

### 2.2 无域名：轮询结算

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `PAYMENT_QUERY_ENABLED` | `true` | 打开内核主动查单任务 |
| `PAYMENT_QUERY_INTERVAL_MS` | `30000` | 查单间隔；越小越实时、对支付宝请求越多 |
| `PAYMENT_QUERY_INITIAL_DELAY_MS` | `15000` | 启动后首次延迟 |
| `PAYMENT_QUERY_AFTER_SECONDS` | `15` | 支付单进入 PAYING 多少秒后才值得查（避免刚下单就查） |
| `ALIPAY_NOTIFY_URL` | 空 | 无域名时**留空**：启动日志会提示“依赖主动查单” |
| `ALIPAY_RETURN_URL` | 空 | 无域名时**留空**：支付完成后不自动跳回业务页面 |

无域名模式下的用户体验：业务前端在用户完成支付后轮询 `PaymentOperations.findByBiz(bizType, bizNo)`（或自己的订单查询接口），看到 `PAID` 后展示成功页。延迟上限约等于一次查单间隔 + 支付宝侧生效时间。

### 2.3 有域名：回调模式

| 环境变量 | 说明 |
|---|---|
| `ALIPAY_NOTIFY_URL` | `https://<域名>/api/payments/alipay/notify`（该路径已在 JwtAuthFilter 白名单，响应纯文本 success/failure） |
| `ALIPAY_RETURN_URL` | 前端订单页地址，代码会再拼 `/{bizNo}` |
| `PAYMENT_QUERY_ENABLED` | 建议保持 `true` 作为兜底（可把间隔调到 60000） |

Nginx/网关要求：HTTPS 证书有效、允许 POST、请求体 ≤ 64KB（控制器有上限）、不要对 `/api/payments/alipay/notify` 加登录态或限流。

### 2.4 账单对账（T+1，可选）

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `ALIPAY_BILL_ENABLED` | `false` | 开启后注册 `ALIPAY` 渠道账单源 |
| `ALIPAY_BILL_TYPE` | `trade` | 交易账单 |
| `ALIPAY_BILL_SMID` | 空 | 商户 SMID（部分账号需要） |
| `ALIPAY_BILL_CHARSET` | `GBK` | 账单文件编码 |

开启后手动对某天账单：

```bash
curl -X POST 'http://127.0.0.1:8084/api/admin/recon/run?channel=ALIPAY&billDate=2026-11-18' \
  -H "Authorization: Bearer <admin token>"
```

差异会在 `t_recon_diff` 落库（LOCAL_ONLY / PROVIDER_ONLY / AMOUNT / STATUS），需要人工核对，不自动改单。账单接口需要商户账号开通对账单权限，且服务器出网。

## 3. 当前实现的能力边界（如实）

已实现：电脑网站支付下单、查单、异步通知验签（RSA2 + app_id/seller_id/金额/幂等）、退款与退款查询确认、**渠道关单**、**主动查单轮询结算**、**支付宝 T+1 账单下载与对账**、发件箱事件（崩溃回收）。

未实现/不在内核：

- 手机网站支付 / App 支付 / 扫码支付 / 微信支付；
- 证书模式（当前仅公钥模式）；
- 退款异步通知、退款对账（退款编排在业务侧，内核只提供退款 SPI 与重试字段）；
- 多租户回调：回调不带租户信息，当前按默认租户 0 处理，SaaS 化前需要按 app_id/商户号反查租户；
- 真实网关验收：需要商户资质与真实小额交易，代码侧已提供无需外网的签名/验签集成测试。

## 4. 迁移到有域名服务器的切换清单

1. DNS 与 HTTPS：域名解析到新服务器，配置证书与 nginx，暴露 80/443。
2. 支付宝开放平台：应用网关/回调地址按新域名配置（电脑网站支付至少配 `notify_url`）。
3. 环境变量：填 `ALIPAY_NOTIFY_URL`、`ALIPAY_RETURN_URL`；`PAYMENT_QUERY_ENABLED` 保留 true 兜底；`ALIPAY_SELLER_ID` 建议配置。
4. 防火墙：允许支付宝回调 IP 访问 `/api/payments/alipay/notify`（见支付宝文档的 IP 段），不要加登录态。
5. 验收（建议顺序）：
   - 沙箱：小额支付 → 收到 `payment_callback_verified` 日志 → 支付单 PAID → 业务侧履约 → 全额退款成功；
   - 生产：低金额真实支付 + 退款，核对支付宝后台交易号/金额/退款状态；
   - 账单：次日开启 `ALIPAY_BILL_ENABLED` 跑一次 ALIPAY 对账，确认 0 差异；
   - 通知失败演练：临时断开回调地址，确认轮询兜底能在一次间隔内把支付单确认成 PAID。

## 5. 排障

关键日志：`payment_initiated`（下单）、`payment_callback_verified/processed`（回调）、`payment_query_settled/expired`（查单）、`payment_query_expired`（过期关单）、`payment_query_job` 相关异常。

| 现象 | 排查 |
|---|---|
| 回调返回 failure | 检查 `ALIPAY_PUBLIC_KEY` 是否支付宝公钥（不是应用公钥）、`app_id` 是否匹配、报文编码是否 UTF-8 |
| 支付成功但业务没反应 | 查 `t_payment_order.status` 是否 PAID、`t_payment_outbox` 是否 SENT；没有监听者时内核会告警 |
| 无域名模式支付后一直 PAYING | 查 `PAYMENT_QUERY_ENABLED` 是否为 true、服务器能否出网访问 `ALIPAY_GATEWAY_URL`、支付单是否已过 `query-after-seconds` |
| 支付宝侧交易已关闭但本地 PAYING | 查 `payment_query_expired` 日志；渠道关单失败会保留 PAYING 等下次重试 |
| 对账报“未接入对账数据源” | `ALIPAY_BILL_ENABLED` 未开启或账单权限未开通 |

网络连通性自检（不需要域名）：

```bash
curl -s -o /dev/null -w '%{http_code}\n' --max-time 10 https://openapi.alipay.com/gateway.do
curl -s -o /dev/null -w '%{http_code}\n' --max-time 10 https://openapi-sandbox.dl.alipaydev.com/gateway.do
```

## 6. 本地验证（无需外网/域名）

- `AlipayProviderIntegrationTest`：`provider=alipay` 真实上下文 + 真实 RSA2 签名回调，验证验签、确认、发件箱全链路；
- `AlipayPaymentGatewayTest`：下单字段、查单状态映射、退款确认、关单；
- `AlipayBillParserTest`：账单 CSV/zip 解析（GBK）；
- `PaymentQueryServiceTest`：查单成功/过期关单/渠道关单失败保留。
